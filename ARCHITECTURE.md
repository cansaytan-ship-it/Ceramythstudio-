┌─────────────────────────────────────────────────────────────────────────────┐
│                         AUTHENTICATION FLOW                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. User registers/logs in → POST /api/auth/register or /login             │
│  2. Backend validates → Hashes password (bcrypt) → Saves to DB             │
│  3. Backend generates JWT token → Returns token + user data                │
│  4. Frontend stores token → localStorage                                   │
│  5. Subsequent requests → Add JWT to Authorization header                  │
│  6. Backend verifies token → Allows/denies access                          │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                         E-COMMERCE FLOW                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. Browse Products → GET /api/products (with filters/pagination)          │
│  2. View Product Details → GET /api/products/:id                           │
│  3. Add to Cart → POST /api/cart (requires auth)                           │
│  4. View Cart → GET /api/cart                                              │
│  5. Update Quantities → PUT /api/cart/:id                                  │
│  6. Checkout → POST /api/orders (creates order, updates stock)             │
│  7. View Orders → GET /api/orders                                          │
│                                                                              │
